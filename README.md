# Небо и приливы

Интерактивная сцена мира «Известный мир» (карта Bacia, D&D 5e): солнце, Небеса и Приливная луна, приливы, погода и ветер к Оку Бури, тени, рельеф, растительность, города, корабли и лодки, Шпиль с ползунком этажей.

**Открыть:** https://nokianyte.github.io/nebo-i-prilivy/

Страница самодостаточная: параметры мира и данные карты встроены в `index.html`. Исходная версия живёт в хранилище Obsidian (`DnD/_Скрипты/небо-и-приливы/view.js` + заметка «Параметры мира (астрономия и климат)») и читает данные оттуда при каждом открытии; эта страница — снимок на дату публикации.
